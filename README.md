# Mission Control: Beyond — The Red Frontier

Single-player story mode for Mission 1 (Mars). A static site: plain HTML, CSS and JavaScript, no build step.

## Run it locally

Open `index.html` in a browser, or serve the folder:

    npx serve .

## Deploy to Vercel

Option A, from the command line (inside this folder):

    npx vercel          # preview deployment
    npx vercel --prod   # production deployment

Accept the defaults. There is no framework and no build command; the output directory is the project root.

Option B, from GitHub: push this folder to a repository, then in Vercel choose
Add New > Project, import the repository, leave Framework Preset as "Other",
leave the build command empty, and deploy.

## Where to change things

- Rover model: built from the Mars Exploration Rover OBJ in `assets/source/`. `python3 tools/obj2rover.py assets/source/Mars_Exploration_Rover_3D.obj js/rover_mesh.js`
  regenerates `js/rover_mesh.js`. `rover()` in `js/models.js` assembles it for each configuration.
- Rover parts, rover instruments and the rover calculator: `js/roverkit.js` (`RK.CAT`, `RK.INS`, `RK.spec`).
- Orbiter instruments: `INST` near the top of `js/game.js` (each entry carries its own guide).
- Balance numbers: `INST`, `SYS`, `OXY`, `TR`, `ORB`, `REG` and `PRE` near the top of `js/game.js`.
- Launch date: `pickWindow()` and `windowOf()` in `js/game.js`. A window is any day inside ten degrees of arrival error, picked once per mission and saved with the state.
- Random event odds: `rollRandom` and `boltP` in `js/game.js`.
- Story lines and characters: `WHO`, `say(...)` calls and the `lines` arrays passed to `Cine.play`.
- Glossary: `TERMS` in `js/game.js`.
- A new cutscene: add a function to `SC` in `js/cutscenes.js`. It receives progress `u` (0 to 1) and time `s` (seconds).
- Scoring: `score()` in `js/game.js`.

## NASA GMAT

The trajectory screen and the cruise use GMAT output. `tools/gmat_pipeline.py` runs GMAT R2026a's console program
(`GmatConsole.exe`; through Wine on Linux or macOS) three times: Earth and Mars positions for every day of the game's
calendar (DE421 ephemeris), a targeting run that finds, for every launch day inside a window, the departure velocity
that reaches Mars, and a propagation run that records each transfer in 2-day steps. To regenerate the data:

    python3 tools/gmat_pipeline.py --gmat "C:/GMAT/R2026a/bin"            # Windows
    python3 tools/gmat_pipeline.py --gmat ~/gmat/bin --wine /usr/lib/wine/wine64   # Linux

The game itself does not run GMAT; it reads the saved results in `js/gmat_data.js`.

## Race mode

"Race other players" on the title screen. One player creates a room and shares its five-character code; up to five
others join; the host starts. Everyone flies the same mission with the same seed. Browsers connect directly
(WebRTC) using PeerJS; the PeerJS library loads from unpkg.com and the free public PeerJS server introduces the
players. Nothing to deploy for it. To run your own PeerJS server, set `window.MCB_PEER={host,port,path}` in
`index.html` before `js/race.js`.

## Notes

- Cutscenes need WebGL and an internet connection for three.js. Without either, a 2D version plays instead.
- "Demo controls" in the footer triggers random events and replays any cutscene.
- Spacecraft numbers are tuned for the game. They are not NASA specifications.
- The Mars map, spectra and radar plots are generated by the game. The NASA findings quoted in the debrief should be checked against the linked archives before presenting.

## Sources and tools

- Mission segments, concept of operations, the six-step design process and "requirements with verification" in the briefing, review and notebook follow NASA's "Design and Develop Science Missions" webinar (Access to Space for All systems-engineering series, 26 March 2025).
- The review board and debrief can export the flight plan as a script for GMAT, NASA's open-source General Mission Analysis Tool (https://sourceforge.net/projects/gmat/). The script is an untargeted starting point and has not been run in GMAT.
- The spacecraft model is assets/spacecraft_3d.glb.
- The rover model is the Mars Exploration Rover OBJ supplied with the project (assets/source/Mars_Exploration_Rover_3D.obj), converted by tools/obj2rover.py. Its wheels can be swapped for generated ones; instruments, power units, antennas, covers and markings are added in code.
- assets/mars.jpg (JPL/Caltech/USGS) and assets/earth.jpg (NASA Blue Marble) are the planet maps shipped in GMAT R2026a's data/graphics/texture folder, resized to 2048x1024.
- Cutscenes are drawn at real size and distance: a 24 m spacecraft, a 62 m launch vehicle, Mars 3,389.5 km and Earth 6,371 km in radius, at the altitudes named in each scene.
